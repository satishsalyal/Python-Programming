# Course Objective

This course aims to introduce students to the fundamentals of Python programming. It focuses on developing problem-solving skills, understanding basic programming constructs, and enabling students to write simple programs for real-world applications.

---

# Course Content

## Unit I – Introduction to Python Programming

- Introduction to programming and Python
- Features and applications of Python
- Installation of Python and working with IDEs (IDLE, Jupyter Notebook)
- Basic syntax and structure
- Keywords and identifiers
- Variables and data types
- Input and output operations using `input()` and `print()`
- Operators in Python

---

## Unit II – Control Structures and Functions

### Decision Making

- `if`
- `if-else`
- `if-elif-else`

### Looping Constructs

- `for` loop
- `while` loop
- Nested loops

### Loop Control Statements

- `break`
- `continue`
- `pass`

### Functions

- Function definition and calling
- Parameters and return values
- Types of functions
  - Built-in functions
  - User-defined functions

---

## Unit III – Data Structures in Python

### Lists

- Characteristics
- Operations

### Sets

- Set operations

### Strings

- Creation
- Indexing
- Slicing
- Operations
- Methods

### Tuples

- Concept
- Operations

### Dictionaries

- Key-value pairs
- Operations
- Built-in functions

---

## Unit IV – File Handling and Introduction to Libraries

### File Handling

- Opening files
- Closing files
- Reading files
- Writing files

### Introduction to Python Libraries

- Basic overview of **NumPy**
- Basic overview of **Pandas**

---

# Course Outcomes

Upon successful completion of this course, students will be able to:

- **CO1:** Understand Python syntax, data types, and basic programming concepts.
- **CO2:** Apply control structures and functions to solve computational problems.
- **CO3:** Utilize Python data structures for efficient data manipulation.
- **CO4:** Develop simple applications using file handling and modular programming concepts.

# Note for Paper Setting

The **External End Semester Theory Examination** will carry **60 marks**.

The question paper will be divided into **two sections: Section A and Section B**.

### Section A

- **4 compulsory short-answer questions**
- One question from each unit
- **3 marks each**

### Section B

- **8 long-answer questions**
- Two questions from each unit
- Students must attempt **one question from each unit**
- **12 marks each**
