# 📝 Question 1 — College Admission

Write a Python program to determine whether a student is eligible for admission.

The program should accept:

* Age
* Percentage
* Entrance-test marks

Create suitable eligibility conditions.

The program should display either:

```text
Eligible for Admission
```

or

```text
Not Eligible for Admission
```

### ⭐ Challenge

Use a **nested `if`** so that the entrance-test condition is checked only after the academic requirement is satisfied.

---

# 🏧 Question 2 — ATM Withdrawal

Write a Python program that accepts:

* Account Balance
* Withdrawal Amount

The program should check:

1. Whether the withdrawal amount is positive.
2. Whether sufficient balance is available.
3. Whether the amount satisfies the withdrawal condition.

If the withdrawal is successful, display the remaining balance.

Otherwise, display an appropriate message.

### Possible Situations

```text
Invalid Amount
Insufficient Balance
Invalid Withdrawal
Successful Withdrawal
```

### ⭐ Challenge

Use **nested `if` statements** to perform the validation step by step.

# ⚡ Question 4 — Electricity Bill

Create a Python program to calculate an electricity bill based on the number of units consumed.

Design your own **three or four consumption slabs**.

For example:

```text
Low Consumption
Medium Consumption
High Consumption
Very High Consumption
```

The program should calculate and display:

```text
Units Consumed
Rate
Bill Amount
```

### ⭐ Challenge

Add an additional condition:

> If the calculated bill exceeds a certain amount, apply an additional charge.

# 🧠 Logic Challenge

Before writing the Python program, answer the following questions **on paper**:

### 1. What inputs are required?

List all the values that the program needs.

### 2. What conditions are required?

Identify every condition needed to solve the problem.

### 3. Which condition should be checked first?

Determine the correct order of decisions.

### 4. Which conditions depend on another condition?

Identify where a **nested `if`** is appropriate.

### 5. What should happen if all conditions are false?

Determine the appropriate `else` action.
